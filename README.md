# 띵동! 보넥도

보넥도 일정·영상·기사·생일카페를 **10분마다 자동으로** 모아서 보여 주는 앱이에요.
GitHub가 무료로 서버 역할을 해요(컴퓨터를 켜 둘 필요 없음).

## 처음 한 번만 설정 (3단계)
1. github.com에서 새 저장소(Repository)를 **Public**으로 만들고, 이 폴더 안의 파일을 모두 올려요.
2. 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 바꿔요.
3. **Actions** 탭 → "보넥도 소식 자동 업데이트" → **Run workflow**를 눌러요.

1~2분 뒤 `https://아이디.github.io/저장소이름/` 주소로 앱이 열려요.
휴대폰에서 이 주소를 열고 **홈 화면에 추가**하면 앱처럼 설치돼요.

## 파일 설명
- `index.html` 앱 화면
- `collect.py` 소식 수집기 (블립 일정, 공식 유튜브, 뮤비, 멤버별 직캠, 구글 뉴스, 생일카페)
- `mvs.json` 공식 뮤비 목록 (새 뮤비는 수집기가 자동으로 추가)
- `.github/workflows/update.yml` 10분마다 수집기를 돌리는 설정
